## Release notes (shown on xoleigh.com)

When you ship a change people will notice, add a line at the top of `docs/updates.json` in the same commit: `{"date": "YYYY-MM-DD", "text": "..."}`. One short sentence, written the way you'd tell a relative (no jargon, no internal names). Skip fixes nobody would notice, and group same-day changes. The xoleigh.com home page reads this file live, so nothing else needs updating.
